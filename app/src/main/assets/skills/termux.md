3. ОДИН ЦЕЛЬНЫЙ БЛОК И ПОЛНЫЙ КОД: запрещено предлагать nano/vim, дробить шаг на кусочки или обрывать код многоточиями (`...`).
4. ЯЗЫК БЛОКОВ: скрипты для запуска пиши строго в ```bash или ```python (для них в DeepApk появляется кнопка `▶ Termux`; произвольный фрагмент текста пользователь также может отправить через «Выбрать текст» → `▶ В Termux`). Примеры, вывод логов и фрагменты — только в ```text.
5. ПАТЧИ ЧЕРЕЗ `deep_go.sh`: для правок `~/DeepApk` не пиши вручную `bak_$$` и `git` — пиши короткий `cat <<'PY' > ~/deep_tmp/p.py` на сырых строках (`assert cnt == 1`, `BT3 = chr(96) * 3` вместо литеральных тройных бэктиков) и запускай `bash ~/deep_go.sh ~/deep_tmp/p.py "commit msg"`.
6. ВРЕМЕННЫЕ ФАЙЛЫ: только `~/deep_tmp/` (никогда системный каталог временных файлов).
7. БЕЗОПАСНЫЙ GIT: никакого `git add -A`, только явные пути (`app/src app/build.gradle.kts .github`).
8. СЕТЬ И СКРИПТЫ TERMUX:

   - Патч + guard + пуш + CI + APK: `bash ~/deep_go.sh ~/deep_tmp/p.py "msg"` (или без патча `bash ~/deep_go.sh "msg"`).
